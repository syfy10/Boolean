Managing State

As your application grows, it helps to be more intentional about how your state is organized and how data flows between components.

Choosing a state library

Most small apps don't need a library at all. When you do, popular options include zustand, jotai, and @reduxjs/toolkit.

Zustand offers a tiny, hook-based API with almost no boilerplate, which makes it a good default for small projects.

Sharing state between components

Lift state up to the closest common parent, or move it into a store when many components need to read and write it.
