FAQ

Common questions.

Does it need Node.js or Python installed?

No. The installer bundles everything. Standard local use needs no Node.js, Python, Ollama, or separate model runner.

Does it phone home?

No telemetry and no tracking. Cloud calls only happen if you add a provider key and explicitly use that model; everything else stays local.

Can I use my own models?

Yes. Download a supported local GGUF model from inside the app, or point it at a model you already have. You can also add a custom API endpoint.

Can I inspect the source?

Yes — browse the public source, releases, and issues on GitHub.

What about macOS or Linux?

Boollm is built for Windows 10/11 (x64) today. macOS and Linux aren't currently supported.
